# Vansco Sales Campaign

Use the left-hand **VANSCO SALES CAMPAIGN** panel below Image Extractor.
Upload an XLSX/XLS/CSV price sheet, select your existing sale PNG in Campaign template,
then select a registration. Imports append to the queue; New Campaign starts a fresh queue
after confirmation. Registration, Sales Location / Location / Site / Branch, WAS, NOW, SAVE and URL aliases are case-insensitive. Sales Location is preserved for display, refresh and registration/location filenames.
Blank SAVE is calculated; discrepancies over £1 are flagged without changing supplied values.
Invalid rows remain visible with warnings and can be corrected under Edit active vehicle.

LOAD DEALERKIT IMAGES is the primary explicit action. It asks Marketing CRM's secure bridge for an exact registration match and full ordered gallery. Duplicate/missing/mismatched stock never replaces an existing photo. Keep Load Images From URL or Upload Image (JPG/PNG/WebP) as fallbacks, then select a thumbnail and use the
existing drag/zoom editor. Metadata is saved synchronously to localStorage; uploaded photo
blobs are held separately in IndexedDB. Returning to a vehicle or refreshing restores its
photo choice, transform, completion state and each price offset. New stock can be entered
under Add New Stock Vehicle. Remaining / Done / All and registration search filter the queue.

Select WAS/NOW/SAVE in Price position and nudge by 2px; Reset Price Position clears that
vehicle's field offsets. Advanced price position exposes X/Y. Each value is left-anchored.
League Spartan Black (900) is the default, with ExtraBold (800), Archivo Black and Anton available. All fonts are bundled locally; drawing/export waits for every chosen font to load. Width controls scale the complete amount horizontally, preserve height and keep the visible left edge of £ fixed. The red WAS line is drawn with
the amount, after the fixed overlay, so it follows the WAS offsets. Normal editor exports
never receive campaign pricing.

**The existing October master is browser-local and is not shipped in this repository.**
It is never replaced or regenerated by this feature. Price coordinates follow the supplied master reference, scaled to 960 × 720:
WAS (30,643)/54px/100%, NOW (215,628)/72px/105%, SAVE (695,43)/72px/105%. Coordinates refer to the visible ink's top/left; the font baseline is measured so fonts share the same approved anchors.
Exact alignment against the browser's uploaded PNG should be visually checked. Calibrate once using Advanced campaign price defaults
(font family, X/Y/font size and width percentage per field), then keep ordinary vehicle adjustments to the nudge buttons.
These defaults belong to the campaign and can support future promotion overlays.

Save PNG & Mark Done renders a fresh 960 × 720 PNG, starts the download with
REGISTRATION-LOCATION.png, marks the row and advances to the next unfinished vehicle.
Export PNG Only keeps the current row open. Browser APIs can confirm download initiation,
not successful completion on disk or a user's Save-dialog cancellation; manually mark
Not Done if a download is cancelled. Done vehicles can be reopened and exported again.
Raw Download ZIP uses extracted remote images; Export All Images also composes uploaded
photos. In a campaign gallery ZIP, each alternative has its own folder and uses the
registration/location PNG filename. The normal extractor, image navigation/deletion, templates and ZIP exports remain.

Remove is available on both template lists and requires confirmation. Built-ins are hidden
using vehicle-image-suite-hidden-template-ids, custom entries are deleted from the existing
library, and Restore Default Templates restores Van Finance and Rent2Buy. Removing the
active campaign template selects another available template. When no templates remain, export is disabled until one is added or restored.

Progress belongs to this browser and origin. Clearing browser data removes saved progress.
A storage error is visible and prevents a change from being accepted as saved.

## Development and verification

- npm run lint
- npm test
- npm run build
- npx playwright install chromium
- npm run test:browser

The extraction parser accepts any Vansco path, src/srcset, lazy/full-size attributes,
og:image, structured image arrays and escaped DealerKit/Dragon2000 URLs. It preserves
signed URLs and takes the largest advertised srcset image. Sites that deliver galleries
only after client-side network calls may require Upload Image until those API payloads are
supported. Unit fixtures cover the source formats; browser tests mock extraction responses.

## DealerKit bridge configuration

The Vehicle Image Suite server proxies GET /api/dealerkit-images?registration=CP16AZW to
https://marketing-crm-six.vercel.app/api/vehicle-image-suite-stock by default. Override the
server-only DEALERKIT_BRIDGE_URL to use another approved CRM environment. No DealerKit
API secrets belong in this application or VITE/browser environment.

The bridge is supplied in Marketing CRM PR #606 and reuses its existing adapter and
credentials. It returns only registration, stock ID and public image URLs, verifies exact
identity again against detail, and rejects duplicate stock. Shared stock and per-vehicle
gallery caches last five minutes per warm server instance. Cold instances may each fetch
a snapshot. There is no Vansco registration search, form discovery or crawler.

Neither PR is deployed by this work. Until the CRM endpoint is separately approved and
deployed, live DealerKit loading shows a clean fallback message. Tests use fixtures; live
DealerKit connectivity still needs checking after deployment. Manual upload and explicit
URL extraction continue to work.
